📋 Daily-Tasks

A modern, lightweight, native desktop task manager for Fedora Linux — with a background reminder daemon, dark mode, live search, and optional Google Drive sync.

⬇ Download RPM View on GitHub

✨ Features

  • Native desktop experience — clean Tkinter UI with a modern clam theme that blends into Fedora/GNOME.
  • 🌙 Dark mode — toggle light/dark; your choice is remembered.
  • 🔍 Live search — filter tasks by description or date as you type.
  • Smart sorting & color-coding — overdue in bold red, due-today in blue, upcoming below.
  • Persistent reminder daemon — auto-starts at login and sends native desktop notifications for due tasks.
  • Safe storage — crash-safe atomic writes with automatic .bak recovery and concurrency-safe access shared by the app and daemon.
  • ☁ Optional Google Drive sync — keep tasks in sync across every machine on the same account, with per-task merging so concurrent edits never lose data.

🚀 Install

No compiling required. Download the latest .rpm from the Releases page, then install with dnf (dependencies are pulled in automatically):

sudo dnf install ./daily-tasks-*.noarch.rpm

Launch it from your application menu by searching for Daily-Tasks. The reminder daemon starts automatically at login.

☁ Cloud Sync (optional)

Sync is off by default and uses rclone as the transport, so Google authentication is handled once by rclone — the app never sees your password and stores no OAuth secrets. After a one-time rclone config, enable sync in the app via ⚙ Configure Sync. Every sync merges the two sides per task (newest wins, deletions tracked as tombstones), so devices — even ones that were offline — converge without data loss.
